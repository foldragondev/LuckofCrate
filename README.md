# Crate Opening Simulator v2

A feature-rich, interactive Python game built with **Tkinter**. Experience the thrill of opening crates, managing a vast inventory, and crafting legendary artifacts in a sleek, cyberpunk-themed interface.

## 🚀 Key Features

### 📦 Unique "Luck Budget" System
Unlike traditional RNG, each crate generates a **Luck Pool**. Every item dropped "spends" a portion of this luck based on its rarity:
- **Common**: 10 Luck
- **Uncommon**: 25 Luck
- **Rare**: 60 Luck
- **Epic**: 150 Luck
- **Legendary**: 400 Luck
- **Mythic**: 1200 Luck
*Will you get one Mythic masterpiece or a mountain of Common treasures?*

### ⚒️ Advanced Crafting & Progression
- **Dynamic Sorting**: Recipes are automatically sorted by completion percentage.
- **Vast Item Pool**: Over 30+ unique items ranging from "Bent Nails" to "Neutron Star Dust".
- **Complex Recipes**: Combine base materials and rare shards to create Mythic Relics.

### ⛏️ Mining & Upgrades
- **Incremental Mining**: Start from $1 and upgrade your mine to increase base yield.
- **Mine-Shards**: Special items that provide a permanent multiplier to your mining income.

### 🎒 Inventory Management
- **Bulk Selling**: Select multiple items using checkboxes and sell them all at once.
- **Batch Bonus**: Earn up to **+100% extra coins** by selling large quantities of items in a single transaction.

### 🎨 Sleek UI/UX
- **Cyberpunk Theme**: A beautiful Dark Blue and Accent Green interface.
- **Animations**: Visual feedback during crate openings with rarity-colored highlights.
- **Responsive Tabs**: Seamlessly switch between the Shop, Inventory, and Crafting menus.

## 🛠️ Installation & Usage

### Prerequisites
- Python 3.x
- Tkinter (usually included with Python)

### Running the Game
1. Download the `game_gui.py` file.
2. Open your terminal or command prompt.
3. Run the following command:
   ```bash
   python game_gui.py
   ```

## 🎮 How to Play
1. **Mine**: Start by clicking the "Mine Coins" button to build your initial capital.
2. **Shop**: Head to the Shop tab to buy crates. Higher-tier crates like the "Godly Crate" have much larger Luck Pools.
3. **Inventory**: Check your drops. Use the checkboxes to select items you want to sell.
4. **Craft**: Visit the Crafting tab to see what you can build. Focus on the recipes at the top—they are the ones you're closest to finishing!
5. **Upgrade**: Don't forget to upgrade your mine to accelerate your progress.
